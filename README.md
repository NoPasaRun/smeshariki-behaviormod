# BehaviorMod

Поведение персонажей: напарник и приказы ему, окно реплик и кат-сцены (запись, редактор, показ, съёмка видео, музыка из mp3).

Часть набора модов «Смешарики» для Minecraft 26.2 (Fabric, Java 25). Общее описание, установка и состав набора — в [корневом README](https://github.com/OWNER/smeshariki-demo#readme).

Если играет один человек, второго смешарика ведёт напарник; приказы отдаются через окно реплик. Кат-сцены записываются и правятся встроенным редактором (клавиша N открывает реестр сцен). Музыка: положите `.mp3` в `data/behaviormod/music/` и выберите в редакторе.

## Клавиши

| Клавиша | Действие |
|---|---|
| J | реплики напарнику |
| Backspace | пропустить кат-сцену |
| N | реестр кат-сцен: играть, править, удалить |

## Сборка

```
./gradlew jar --no-daemon -Dorg.gradle.jvmargs=-Xmx900m
```

Результат — `build/libs/behaviormod-1.0.0.jar`. Моды компилируются против соседних jar в `../<Мод>/build/libs/`, порядок сборки: UiLib → GameplayMod, ManagementMod → WorldMod → BehaviorMod, BuildMod → LevelMod.
